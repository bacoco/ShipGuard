# ShipGuard 2.10.0

## Delivered scope

- Explicit report-only `sg-pre-review`: preserve the original request, search interfaces and usages
  separately, follow active consumers, and recommend reuse or the smallest justified change.
- Optional additive `prereview-results.json` version 1.0 and existing dashboard Pre-Review tab.
  Partial, invalid, and undetermined reports are not presented as PASS.
- Root Logic contract conflicts enter Findings as unresolved concerns with source references.
- Existing lane contracts, CLI commands, mission-lock hook, and report-only defaults remain stable.
- Skill catalogs, architecture, output contract, and review prerequisites are documented.

#79 is delivered within the simplified scope described in
[2026-09-15-prereview-issue-79.md](2026-09-15-prereview-issue-79.md).
External plans/tasks are compared only when supplied; ShipGuard does not create a planning system.
Context references are declarations, not a complete captured model request.
Model evaluations were stopped by user instruction and are not a delivery gate or evidence of
semantic guarantees. Technical tests establish packaging, source citation integrity, dashboard
consumption, and CLI compatibility; they do not establish the quality of every model's judgment.

## Separate remaining feature

#77 concerns optional dialogue hooks. No new UserPromptSubmit, PreToolUse, PostToolUse, or Stop
controller is delivered here. The standalone GrillGoal skill remains independent.

## Updating

Update ShipGuard from its existing marketplace with the host plugin manager. Version metadata is
2.10.0 in both Claude and Codex manifests. Start a new session if the host retains an older loaded
plugin. Do not edit a cached plugin by hand.
