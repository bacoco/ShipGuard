### Singleton Verification Gate + fresh-instance verifiers — [#53](https://github.com/bacoco/ShipGuard/issues/53)

**Source:** [minwoo-data/prism](https://github.com/minwoo-data/prism) + [dsifry/metaswarm](https://github.com/dsifry/metaswarm) + [c0rrey/ant-farm](https://github.com/c0rrey/ant-farm)
**Score:** 4.2/5.0 (Impact: 4, Novelty: 4, Applicability: 5, Effort: 4)

Auto-confirm findings reported independently by 2+ agents; batch only single-agent findings to a fresh verifier (new context, no finder transcript) that must produce file:line evidence or a repro. Verification effort lands exactly where false-positive risk lives, gated mechanically (script-verified PASS/FAIL), not by prose.

**Affected skill:** `sg-code-audit` — **Mutation type:** `restructure`

### Fix-Safety Tiering: auto / test-first / human-review — [#55](https://github.com/bacoco/ShipGuard/issues/55)

**Source:** [thtskaran/claude-skills](https://github.com/thtskaran/claude-skills) (deslop)
**Score:** 4.2/5.0 (Impact: 4, Novelty: 4, Applicability: 5, Effort: 4)

Every finding gets `fix_tier`: Tier 1 safe mechanical fixes auto-applied, Tier 2 requires characterization tests before fixing, Tier 3 human-only. Encodes "working code is not a bug" structurally in the fix phase instead of trusting per-agent judgment.

**Affected skill:** `sg-code-audit` (fix phase) — **Mutation type:** `add_constraint`

### Learnings ledger with provenance + usage counters + promotion gates — [#56](https://github.com/bacoco/ShipGuard/issues/56)

### Deterministic visual diff layers: DOM + pixel + change classification — [#57](https://github.com/bacoco/ShipGuard/issues/57)
